OSplit Web

Audio import, stem separation, playback, and export run in your browser. Source files, stems, projects, and selected ONNX models are stored locally in IndexedDB.

Browser requirements

Use a current Chrome, Edge, Firefox, or Safari release. Model inference may be slow or exceed memory limits on mobile devices. Browser storage limits vary.

Each project picks a separation model, and the project page shows whether WebGPU is available. Demucs v4 gives six stems (vocals, guitar, piano, drums, bass, other) and better separation, but is slower than Spleeter (about 1.2× Spleeter on a desktop GPU, more on weaker ones) and its piano stem is weak; it needs WebGPU and never runs on the CPU. The first run downloads 115 MB. Spleeter gives five stems and is fast on any device: WebGPU when available, otherwise the WebAssembly CPU provider. The first run downloads 197 MB. The ONNX Runtime is downloaded as well.

Background work

Processing runs in a worker while the app is open. Browsers can suspend or terminate tabs, so work is not guaranteed to continue after leaving or closing the app. A stopped task is marked interrupted and can be restarted; source audio and completed project data remain stored locally.

URL download limitations

The browser yt-dlp runtime requires JavaScript Promise Integration and a network connection. Browser-only retrieval is subject to CORS and site restrictions; YouTube and many providers may fail. OSplit does not use a proxy or send media to a processing server. Importing a local audio file is the reliable alternative.

yt-dlp browser runtime prerequisites: Chrome 137+, Firefox 153+, or Safari 27+. For privacy and security, downloaded runtime updates are checked against the SHA-256 digest published by PyPI.

Speed, key and loop

The player can change the speed (50–150%) and key (±12 semitones) of a project and repeat an A–B loop. Key and speed changes use the Signalsmith Stretch pitch shifter (MIT), an AudioWorklet loaded on first use; it adds about 120 ms of delay. Loops are seamless with decoded playback; with streaming playback, used for long tracks on low-memory devices, the jump back to the loop start leaves a short gap.

Shortcuts: -/= speed, ,/. key, 0 resets both, [/] set the loop start and end at the playhead, L turns the loop on or off (or makes one, 4 bars from the playhead) and Shift+L clears it.

Zoom: scroll on the overview strip above the ruler, or use Ctrl/⌘ + scroll or a pinch on the lanes. Drag the overview or the lanes to move along; drag the loop edges, while the loop is on, to adjust them, or inside the loop on the bar ruler to move it.

Tempo, beats and click

After separation, OSplit finds the tempo, beats and bar starts of the stems on this device, in a worker. Half or double tempo errors are possible and can be corrected with ×2/÷2 in the tempo panel, along with beats per bar, the bar start and tap tempo. Music without a steady pulse may show no grid, or a low-confidence one that loops don't snap to. The click track is sample-accurate with decoded playback; with streaming playback it can be some 30 ms off, and a background tab can delay or drop clicks.

Shortcuts: B loops the current bar (again to double it), C turns the click on or off, T taps the tempo while the tempo panel is open. Dragged loop edges snap to beats; hold Alt for bars, Shift for none.

Key and chords

The analysis also finds the key and the chords, from the stems without the drums. Chords are simplified to major and minor triads (sevenths and other chords show as their nearest triad), and a key can be mistaken for its relative major or minor, which the key panel offers as the alternative; you can also set the key there. Chord names follow the key shift unless set to show the original. The chord sheet (.txt) and .lab exports are named as shown.

Storage and privacy

All projects are scoped to this browser profile and device. Clearing site data removes them; to keep a project or move it to another device, use Export project file and import the .osplit file there. Where the site offers cloud storage, projects can also sync to your own Dropbox or OneDrive from the project list; OneDrive asks you to sign in again after a day without use. OSplit asks the browser to preserve its storage when supported, but browser quota and eviction policies still apply. Stems are stored as lossless FLAC, typically about half the size of WAV. Exports are FLAC by default, or WAV when chosen in the mixer, and are saved through your browser's download handling.
