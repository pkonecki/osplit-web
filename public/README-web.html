OSplit Web

Audio import, stem separation, playback, and export run in your browser. Source files, stems, projects, and selected ONNX models are stored locally in IndexedDB.

Browser requirements

Use a current Chrome, Edge, Firefox, or Safari release. WebGPU is preferred when available; the WebAssembly CPU provider is used as a fallback. Model inference may be slow or exceed memory limits on mobile devices. The first run downloads about 98 MB for Low quality (FP16) or 197 MB for High quality (FP32), plus the ONNX Runtime. Browser storage limits vary.

Background work

Processing runs in a worker while the app is open. Browsers can suspend or terminate tabs, so work is not guaranteed to continue after leaving or closing the app. A stopped task is marked interrupted and can be restarted; source audio and completed project data remain stored locally.

URL download limitations

The browser yt-dlp runtime requires JavaScript Promise Integration and a network connection. Browser-only retrieval is subject to CORS and site restrictions; YouTube and many providers may fail. OSplit does not use a proxy or send media to a processing server. Importing a local audio file is the reliable alternative.

yt-dlp browser runtime prerequisites: Chrome 137+, Firefox 153+, or Safari 27+. For privacy and security, downloaded runtime updates are checked against the SHA-256 digest published by PyPI.

Storage and privacy

All projects are scoped to this browser profile and device. Clearing site data removes them. OSplit asks the browser to preserve its storage when supported, but browser quota and eviction policies still apply. Stems are stored as lossless FLAC, typically about half the size of WAV. Exports are FLAC by default, or WAV when chosen in the mixer, and are saved through your browser's download handling.
